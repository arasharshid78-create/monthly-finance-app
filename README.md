# دخل و خرج

اپلیکیشن مدیریت اقساط، هزینه‌های روزمره و درآمد ماهیانه با تقویم شمسی.

## امکانات
- ثبت اقساط با تعیین تعداد ماه و پیگیری وضعیت پرداخت هر ماه
- ثبت هزینه‌های روزمره با تاریخ شمسی
- ثبت حقوق ثابت ماهیانه و درآمدهای اضافه
- مشاهده‌ی تاریخچه‌ی کامل هر ماه (گذشته و آینده)
- طراحی مینیمال و کاملاً فارسی
