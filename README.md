# حساب و کتاب ماهیانه — راهنمای انتشار

## محتوای این پکیج
- `index.html` — خود برنامه
- `manifest.json` — مشخصات PWA (نام، آیکون‌ها، رنگ)
- `service-worker.js` — کش کردن برای کارکرد آفلاین
- `icons/` — آیکون‌های سکه‌ای در سایزهای لازم

## مرحله ۱: هاست کردن روی یک دامنه واقعی (رایگان)
گوگل‌پلی روی دامنه‌ی claude.ai اپ قبول نمی‌کند، پس باید این فایل‌ها روی یک آدرس مستقل (https) قرار بگیرند. ساده‌ترین راه رایگان:

**با GitHub Pages:**
1. یک ریپازیتوری جدید در GitHub بساز.
2. تمام فایل‌های این پوشه (`index.html`, `manifest.json`, `service-worker.js`, پوشه `icons`) را در ریشه‌ی ریپازیتوری آپلود کن.
3. در تنظیمات ریپازیتوری (Settings → Pages) گزینه‌ی انتشار از شاخه‌ی `main` را فعال کن.
4. بعد از چند دقیقه یک آدرس شبیه `https://username.github.io/repo-name/` فعال می‌شود.

(روش‌های دیگر: Netlify یا Vercel هم رایگان و حتی ساده‌ترند — فقط پوشه را drag & drop می‌کنی.)

## مرحله ۲: تبدیل به اپ اندرویدی (TWA) با PWABuilder
1. برو به **pwabuilder.com**
2. آدرس سایتی که در مرحله‌ی ۱ ساختی را وارد کن.
3. PWABuilder به‌طور خودکار manifest و آیکون‌ها را می‌خواند و امتیاز PWA را نشان می‌دهد.
4. روی گزینه‌ی **Package for Store → Android** بزن.
5. یک فایل `.aab` (Android App Bundle) دانلود می‌شود — همین فایل برای آپلود در گوگل‌پلی لازم است.

## مرحله ۳: انتشار در Google Play Console
1. یک حساب در **play.google.com/console** بساز (هزینه‌ی یک‌بار حدود ۲۵ دلار).
2. یک اپ جدید بساز، فایل `.aab` را آپلود کن.
3. اسکرین‌شات، توضیحات و دسته‌بندی (مالی / Finance) را تکمیل کن.
4. برای انتشار ارسال کن (بررسی گوگل معمولاً چند روز طول می‌کشد).

## نکته
داده‌های کاربر در `localStorage` مرورگر/برنامه ذخیره می‌شود — یعنی هر کاربر فقط اطلاعات خودش را می‌بیند و چیزی به سرور فرستاده نمی‌شود.
